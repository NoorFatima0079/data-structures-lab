# 📚 Data Structures Lab

Data Structures lab tasks implemented in Java.

## 💻 Language
Java (JDK 21)

## 🔗 Task 1: Stack and Queue using Linked List
Folder: Task1-Stack-Queue-LinkedList

- Stack (push, pop, peek, display) using a linked list
- Queue (enqueue, dequeue, peek, display) using a linked list

How to run:
    javac StackQueueLinkedList.java
    java StackQueueLinkedList

## 🔢 Task 2: 2D Array and Circular Queue using Array
Folder: Task2-2DArray-CircularQueue

- 2D array: input, display, row sums and column sums
- Circular Queue (enqueue, dequeue, display) using an array

How to run:
    javac ArrayCircularQueue.java
    java ArrayCircularQueue
